About this table

The table is a copy of the IANA HTTP Status Code Registry as read on 14 November 2026. Rows with a range, such as 104-199, are numbers that are not assigned. 418 is listed as unused in RFC 9110. Codes with a link have a page here with a real response. Codes that CDNs and servers add on their own, such as 520 or 499, are not in the registry.

This is an independent guide. It is not connected with the IETF, IANA, any browser maker or any company named here. Meanings were checked against the RFC texts on 14 November 2026. Responses shown were recorded on 14 November 2026 from a small test server on the author's own computer.
