HTTP status code classes: 1xx to 5xx

The first digit tells you the kind of answer. The registry numbers below come from the IANA HTTP Status Code Registry.

The five classes

ClassMeaningCodes registered by IANAExplained on this site
1xxInformational5none
2xxSuccess10200, 201, 202, 204, 206
3xxRedirection9301, 302, 303, 304, 307, 308
4xxClient error29400, 401, 403, 404, 405, 406, 408, 409, 410, 413, 414, 415, 416, 418, 422, 426, 429, 431, 451
5xxServer error11500, 501, 502, 503, 504, 505, 511

Reading a code quickly

  1. 1xx: not a final answer. The server says "carry on" (100) or sends early hints (103).
  2. 2xx: it worked.
  3. 3xx: go somewhere else, or use your saved copy (304).
  4. 4xx: the request has a problem: wrong address, no permission, bad data, too many requests.
  5. 5xx: the server has a problem. The same request may work later.

Who should fix it

A 4xx means the sender should change something before trying again. A 5xx means the same request may succeed later and the site owner should look at the server. Automatic retries make sense for 5xx and for 429 (after waiting), not for most other 4xx.

Codes that are not in the standard

Some companies add their own codes, such as 520 to 530 from content delivery networks, or 499 in some servers. They are not in the IANA registry and their meaning depends on the company that sends them: check their documentation.

Is the text after the number important?

No. The text is a hint for people. Programs use the number only, and HTTP/2 and HTTP/3 do not carry the text at all.

Where is the full list?

On the all status codes page of this site, copied from the IANA registry.
