MEMORY_MANAGEMENT blue screen: how to test and fix

Windows found a serious error in how memory was being used. Faulty RAM is the first suspect, but drivers and damaged system files can cause it too.

What you seeStop code: MEMORY_MANAGEMENT

What the code means

Memory, or RAM, is where Windows keeps everything it is working on. The memory manager keeps track of which program holds which part. This stop code appears when that record is found to be corrupt: a memory chip returned the wrong data, or a driver wrote where it should not.

Step 1: test the memory

Windows has a tester built in.

  1. Save your work. Press Windows key + R, type mdsched and press Enter.
  2. Choose Restart now and check for problems.
  3. The computer restarts into a blue test screen. Let it finish; it takes ten minutes to an hour, longer with more memory.
  4. Windows starts again and shows the result in a notification. If you miss it: right-click Start › Event Viewer › Windows Logs › System, then Find "MemoryDiagnostics-Results".
  • "Hardware problems were detected": a memory module is faulty. Go to step 2.
  • No errors: memory is probably fine. Go to step 3. (The built-in test is quick, not exhaustive; errors that appear only when the computer is hot can escape it.)

Step 2: if memory is faulty

On a desktop, and on laptops with a memory cover:

  1. Shut down, switch off at the wall and unplug. On a laptop, also disconnect the battery if it is removable. Touch a bare metal part of the case to discharge static.
  2. Press the clips at each end of the memory module, lift it out, and push it back firmly until both clips click. A module that has worked loose gives exactly this error.
  3. If there are two modules, test with one at a time, in the same slot. The combination that crashes names the bad module.
  4. Replace the faulty module with one of the same type and speed. Memory often carries a long warranty; check with the seller.

Many thin laptops have memory soldered to the board. Those need the service centre.

Step 3: if memory passes the test

  1. Update drivers, graphics first: Settings › Windows Update › Advanced options › Optional updates, or the maker's website.
  2. Repair system files with DISM and sfc. See repair commands.
  3. Remove recent additions: new programs, especially antivirus, VPNs and overclocking or RGB utilities.
  4. Turn off overclocking and XMP/EXPO memory profiles in the BIOS if you enabled them. Memory running faster than it can manage produces this code.
  5. Check the disk with chkdsk C: /f, because Windows also uses disk space as extra memory (the page file).
  6. Check for heat: clean the vents and fans.

Is it urgent?

Yes, if it repeats. Faulty memory silently corrupts files as they are saved, so documents and photographs can be damaged without any message. Back up important files to another drive, and avoid long saves and updates until it is fixed. See back up first.

Does this error mean I need more RAM?

No. It is about faulty memory or a misbehaving driver, not about having too little. Too little memory makes a computer slow; it does not cause blue screens.

Can I keep using the computer?

For light work, with care, after backing up. Do not install Windows updates or do important work on a machine whose memory test fails.

For Windows 11 and Windows 10. Written in November 2026. Menus move between updates; use the search box in Settings if a name differs. Back up important files before any step that resets, repairs a disk or opens the computer. This is an independent guide, not connected with Microsoft.
