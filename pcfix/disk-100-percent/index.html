PC Fix › Slow or full

Disk usage at 100% in Task Manager

The disk is being asked to do more than it can. Either one program is hammering it, or the disk is old, nearly full or failing.

What you seeTask Manager › Performance: Disk 0 (C:) 100%

When it is normal

For a few minutes after starting, during Windows updates, antivirus scans, large copies and game installs, a busy disk is expected. On a computer with a mechanical hard disk (HDD), even ordinary tasks can hold it at 100 per cent. It is a problem when it stays there for long periods with nothing obvious going on.

Step 1: see who is using the disk

  1. Press Ctrl + Shift + Esc and open the Processes tab.
  2. Click the Disk column heading to sort, highest first.
  3. Note the top names. For more detail: Performance tab › Open Resource Monitor › Disk tab, which lists the very files being read and written.

Step 2: match the name to the fix

Antimalware Service ExecutableWindows Security scanningLet the scan finish. If it is constant, check that no second antivirus is installed

Step 3: general fixes

  1. Restart the computer. Not shut down and start: Restart, which also clears a pending update.
  2. Free space. A disk over 90 per cent full struggles. See low disk space.
  3. Check the disk for errors: open Terminal (Admin), run the command, answer Y and restart.
chkdsk C: /f
  1. Repair system files with DISM and sfc. See repair commands.
  2. Scan for malware: Windows Security › Virus & threat protection › Scan options › Full scan.
  3. Update storage drivers: Settings › Windows Update › Advanced options › Optional updates.

Step 4: on an old hard disk, turn off SysMain

If, and only if, the computer has a mechanical hard disk and SysMain is at the top of the list:

  1. Press Windows key + R, type services.msc, press Enter.
  2. Find SysMain, double-click, press Stop, set Startup type to Disabled, press OK.

To undo it, set Startup type back to Automatic and press Start. Leave Windows Search and Windows Update services alone; disabling them causes more trouble than it saves.

Step 5: check the disk's health

Task Manager › Performance › Disk shows the type: SSD or HDD. In Settings › System › Storage › Advanced storage settings › Disks & volumes, choose the disk › Properties to see its health status where the drive reports one. Warnings there, slow chkdsk runs with bad sectors, or clicking noises mean the disk is failing: back up now.

The lasting cure

A computer that starts from a mechanical hard disk will sit at 100 per cent whatever you tune. Moving Windows to an SSD removes the problem altogether and is the best upgrade for an older machine.

Is 100% disk usage harmful?

It does not damage the disk, but the computer is nearly unusable while it lasts, and constant heavy use shortens an old hard disk's life.

Should I disable Windows Search?

Only as a test. Without the index, searching files and the Start menu becomes slow. Indexing calms down by itself once it has caught up.

For Windows 11 and Windows 10. Written in November 2026. Menus move between updates; use the search box in Settings if a name differs. Back up important files before any step that resets, repairs a disk or opens the computer. This is an independent guide, not connected with Microsoft.
