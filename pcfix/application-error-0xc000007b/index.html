"The application was unable to start correctly (0xc000007b)"

The program tried to load a helper file of the wrong kind, usually a 32-bit file where a 64-bit one was needed. Reinstalling the runtime libraries cures most cases.

What you seeThe application was unable to start correctly (0xc000007b). Click OK to close the application.

What the code means

Programs do not carry all their own code. They borrow common helper files, called DLLs, that Microsoft and others supply: the Visual C++ runtime, DirectX, the .NET Framework. Error 0xc000007b means "invalid image format": one of those helper files exists but is the wrong type or is damaged, most often a 32-bit version sitting where the program expected 64-bit, or the other way round. It appears mainly with games and older programs.

Fixes, in the order to try them

1. Restart, then run as administrator. Right-click the program's icon › Run as administrator. If that works, set it permanently: right-click › Properties › Compatibility › tick "Run this program as an administrator".

2. Install the Visual C++ Redistributables, both kinds. This is the fix in most cases.

  1. Go to Microsoft's official page for the "Latest supported Visual C++ Redistributable downloads" (on learn.microsoft.com).
  2. Download both the x86 and the x64 installers for Visual Studio 2015 to 2022. A 64-bit Windows needs both, because 32-bit programs use the x86 one.
  3. Run each. If it offers Repair, choose Repair.
  4. Restart.

Older games may also need the 2013, 2012 or 2010 versions, which are listed lower on the same Microsoft page. Install the x86 and x64 pair of the year the game asks for.

3. Install the DirectX End-User Runtime, for games. Microsoft's "DirectX End-User Runtime Web Installer" adds the older DirectX files that many games still use. Download it only from microsoft.com.

4. Turn on .NET Framework 3.5, for older programs. Press the Windows key, type Turn Windows features on or off, tick .NET Framework 3.5, press OK and let Windows download it.

5. Repair or reinstall the program. Settings › Apps › Installed apps › the three dots › Modify or Uninstall. For games in a launcher, use its "Verify integrity of game files" or "Repair" option, which replaces wrong files in the game's own folder.

6. Install Windows updates and the graphics driver from the card maker's site.

7. Repair system files with DISM and sfc. See repair commands.

8. Check the disk: chkdsk C: /f in Terminal (Admin), then restart.

What not to do

Do not download single DLL files from "DLL download" websites, and do not copy DLLs into System32 by hand. That is how the wrong-type file got there in many cases, and such sites are a common source of malware. The official installers above put the right files in the right places.

If only one program fails

  • Check that the program suits your Windows: a 64-bit-only program will not run on 32-bit Windows (Settings › System › About › System type).
  • Try compatibility mode: right-click the program › Properties › Compatibility › Run this program in compatibility mode for an earlier Windows.
  • Install it to a simple folder such as C:\Games\Name, not inside a synced or protected folder.
  • Add the game's folder to the exclusions of your antivirus if it is quarantining a file, but only for software from a source you trust.
Is 0xc000007b a virus?

No. It is a mismatch between a program and a helper file. Pirated or "cracked" software often triggers it, and that software is a real malware risk.

Do I need both x86 and x64 redistributables on 64-bit Windows?

Yes. 64-bit Windows runs both kinds of program, and each kind uses its own set.
