Wi-Fi option missing, or network not showing

Either Windows cannot use its Wi-Fi adapter, or the adapter works and cannot hear your router. The fixes differ.

What you seeNo Wi-Fi networks found / the Wi-Fi tile is missing / only a globe or aeroplane icon

A. The Wi-Fi switch itself is missing or greyed out

  1. Flight mode. Press Windows key + A and check that Flight mode is off. Many laptops also have a key with an aeroplane or antenna picture (often with Fn); press it once.
  2. Restart the computer. Use Restart, not shut down.
  3. Is the adapter enabled? Press Windows key + R, type ncpa.cpl, press Enter. If Wi-Fi is grey and says Disabled, right-click it › Enable.
  4. Is it in Device Manager? Right-click Start › Device Manager › Network adapters. Look for a name with "Wireless", "Wi-Fi", "WLAN" or "802.11". - A down-arrow on its icon: right-click › Enable device. - A yellow warning mark: right-click › Uninstall device, then restart, so that Windows reinstalls it. - Not listed at all: click View › Show hidden devices, then Action › Scan for hardware changes. If it is still absent, the driver is missing or the adapter has failed.
  5. Check the WLAN service. Windows key + R › services.msc › WLAN AutoConfig should be Running with Startup type Automatic. If not, double-click, set Automatic, press Start.
  6. Reinstall the driver. Use a cable or your phone's USB tethering to get online, then Settings › Windows Update › Advanced options › Optional updates, or download the wireless driver for your exact model from the laptop maker's support page.
  7. Power saving. Device Manager › the wireless adapter › Properties › Power Management › untick "Allow the computer to turn off this device to save power".
  8. Network reset: Settings › Network & internet › Advanced network settings › Network reset.

If the adapter never appears, a small USB Wi-Fi adapter is a cheap replacement for a failed built-in one.

B. Other networks show, but not yours

The computer is fine; it cannot hear your router.

  1. Restart the router and stand close to it.
  2. Is the name hidden? If the router is set not to broadcast its name, join by hand: Settings › Network & internet › Wi-Fi › Manage known networks › Add network.
  3. The band. An older laptop may support only 2.4 GHz. If the router sends only 5 GHz, or one combined name, the laptop may not see it. In the router's wireless settings, turn the 2.4 GHz band on with its own name.
  4. The channel. A router set to an unusual channel or a very wide channel width can be invisible to some adapters. In the router's wireless settings, set the channel to Auto.
  5. Security type. A router set to WPA3 only can be invisible to old adapters. Choose WPA2/WPA3 mixed.
  6. Check on a phone. If the phone cannot see the network either, the router's Wi-Fi is off or faulty; look for its WLAN button and light.

C. No networks at all, though the switch is on

  • Toggle Wi-Fi off and on; restart.
  • Run the troubleshooter: Settings › System › Troubleshoot › Other troubleshooters › Network and Internet.
  • In Terminal (Admin), run netsh winsock reset, then restart.
  • Update the wireless driver (step A6). A faulty driver after an update is the usual cause; Device Manager › adapter › Properties › Driver › Roll Back Driver undoes it.

Useful to know

To see what the adapter supports and hears, open Terminal and run:

netsh wlan show drivers
netsh wlan show networks

The first lists the radio types supported (802.11n, ac, ax) and the second every network in range with its signal strength.

Why did Wi-Fi disappear after a Windows update?

The update replaced the wireless driver with one that does not suit your adapter. Roll the driver back, or install the maker's own driver.

My laptop shows Wi-Fi only when the charger is plugged in. Why?

A power-saving setting is switching the adapter off on battery. Change the adapter's Power Management setting (step A7).
