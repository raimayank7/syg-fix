How to start Windows in Safe Mode

Safe Mode starts Windows with only its own essential files and drivers. If a problem disappears in Safe Mode, something you installed is causing it.

What Safe Mode is for

In Safe Mode, Windows loads without third-party drivers, start-up programs, and most services. The screen looks plain, with "Safe Mode" in the corners. Use it to:

  • find out whether a fault is in Windows itself or in something added later;
  • uninstall a program, driver or update that crashes the normal start;
  • run a malware scan while the malware is not running;
  • delete a file that is locked in normal mode.

Safe Mode with Networking adds the network drivers so that you can download a driver or tool. Sound, printing and many devices do not work in Safe Mode; that is expected.

Way 1: from Settings (Windows is running)

  1. Settings › System › Recovery (Windows 10: Settings › Update & Security › Recovery).
  2. Beside Advanced startup, click Restart now.
  3. On the blue screen: Troubleshoot › Advanced options › Startup Settings › Restart.
  4. When the list appears, press 4 (or F4) for Safe Mode, or 5 (F5) for Safe Mode with Networking.

Way 2: from the sign-in screen or Start menu

Hold Shift and click Power › Restart. Keep Shift held until the blue screen appears. Continue from step 3 above.

Way 3: when Windows will not start

  1. Switch on. As soon as the Windows logo or spinning dots appear, hold the power button until the computer switches off.
  2. Do this three times in a row. On the next start Windows shows "Preparing Automatic Repair" and then the recovery screen.
  3. Choose Advanced options › Troubleshoot › Advanced options › Startup Settings › Restart, then press 4 or 5.

If your drive is encrypted, Windows may ask for the BitLocker recovery key first; it is kept in your Microsoft account at account.microsoft.com/devices/recoverykey.

Way 4: with System Configuration

  1. Press Windows key + R, type msconfig, press Enter.
  2. On the Boot tab, tick Safe boot (Minimal, or Network), click OK and restart.

Windows will start in Safe Mode every time until you undo this: open msconfig again, untick Safe boot, and restart. Do not use this way if you are unsure of your password, because a PIN may not work in Safe Mode and you would be locked into it.

What to do once in Safe Mode

If the problem is...Do this
Gone in Safe ModeA program, driver or start-up item is the cause. Uninstall what you added last: Settings › Apps, or Device Manager › the device › Uninstall or Roll Back Driver
Still there in Safe ModeWindows files or hardware are at fault. Run the repair commands, then think of System Restore or hardware tests
Began after an updateSettings › Windows Update › Update history › Uninstall updates
Suspected malwareWindows Security › Virus & threat protection › Scan options › Full scan

System Restore, Device Manager, Control Panel, Command Prompt and File Explorer all work in Safe Mode.

Signing in

Safe Mode may ask for your password, not your PIN or fingerprint. For a Microsoft account, that is the account's password; use Safe Mode with Networking if you have recently changed it.

How to leave Safe Mode

Simply restart. Windows returns to normal mode, unless you used msconfig (Way 4), in which case untick Safe boot first. If it keeps coming back to Safe Mode, run this in Terminal (Admin) and restart:

bcdedit /deletevalue {current} safeboot
Does Safe Mode delete anything?

No. It only changes what Windows loads for that one session.

Why is the screen resolution low in Safe Mode?

The normal graphics driver is not loaded, so Windows uses a basic one.

Does F8 still work at start-up?

Not on modern computers. Windows now starts too quickly for the old F8 key; use one of the four ways above.
