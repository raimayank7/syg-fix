Wi-Fi connected but no internet

First find out whether the problem is the internet line, the router or this one computer. A phone on the same Wi-Fi tells you in a minute.

What you seeNo internet, secured / Connected, no internet / a globe icon in place of the Wi-Fi icon

Step 1: is it the line, or the computer?

Connect a phone to the same Wi-Fi, with mobile data switched off, and open a website.

  • The phone has no internet either: the fault is the router or the internet line. Go to part A.
  • The phone works: the fault is in this computer. Go to part B.

A. Nothing on the Wi-Fi has internet

  1. Restart the router and the modem or fibre box. Switch both off, wait one minute, switch on the fibre box or modem first, wait for its lights to settle, then the router.
  2. Look at the lights. A red "LOS" or "Internet" light on a fibre box means the line itself is down: call the provider.
  3. Check the account: an unpaid bill or used-up data pack gives exactly this symptom, sometimes with a provider's notice page.
  4. Still down after ten minutes: report it to the provider.

B. Only this computer has no internet

Try each step, then test a website.

  1. Turn Wi-Fi off and on, or flight mode on and off, from the quick settings panel (Windows key + A).
  2. Restart the computer.
  3. Forget the network and join again: Settings › Network & internet › Wi-Fi › Manage known networks › your network › Forget. Then connect and type the password afresh.
  4. Turn off VPN and proxy. Disconnect any VPN app. Then Settings › Network & internet › Proxy: "Automatically detect settings" on, "Use a proxy server" off.
  5. Check date and time. A wrong clock stops secure sites from loading. See date and time wrong.
  6. Run the troubleshooter: Settings › System › Troubleshoot › Other troubleshooters › Network and Internet.
  7. Reset the network settings by command. Open Terminal (Admin) and run these one at a time, then restart.
ipconfig /flushdns
ipconfig /release
ipconfig /renew
netsh winsock reset
netsh int ip reset
  1. Set addresses back to automatic: Settings › Network & internet › Wi-Fi › your network's properties › IP assignment and DNS server assignment both Automatic (DHCP).
  2. Update or reinstall the Wi-Fi driver. Right-click Start › Device Manager › Network adapters › right-click the wireless adapter › Uninstall device (do not tick "attempt to remove the driver"), then restart. Windows reinstalls it.
  3. Network reset, the complete version: Settings › Network & internet › Advanced network settings › Network reset › Reset now. The computer restarts and forgets all Wi-Fi passwords and VPN set-ups, so have your Wi-Fi password ready.

Reading the result of ipconfig

In Terminal, type ipconfig and find "Wireless LAN adapter Wi-Fi".

IPv4 AddressMeaning
192.168.x.x or 10.x.x.x, with a Default GatewayThe link to the router is fine. The trouble is DNS, proxy, or the line
169.254.x.xThe router did not give this computer an address. Restart the router; do steps 7 and 9
No address, "Media disconnected"Not connected to the Wi-Fi at all. See Wi-Fi not showing

If websites fail but apps work

Chat or video apps working while the browser shows "can't find the site" points to DNS. See DNS server not responding.

What does "No internet, secured" mean?

"Secured" says the Wi-Fi link to the router is encrypted and working. "No internet" says Windows could not reach the internet through it.

Why does it work on mobile hotspot but not on home Wi-Fi?

Then the computer is fine and the home router or line is at fault: restart the router and check with the provider.
