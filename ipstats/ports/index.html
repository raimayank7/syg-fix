Common port numbers and what they are for

The port numbers you are most likely to meet, with the service that normally uses each. Type a number or a name to filter.

What a port is

An IP address gets data to the right device. A port number gets it to the right program on that device. A computer can run a web server, a mail server and a game at once on one address, and the port, a number from 0 to 65,535, says which of them a piece of data is for. An address and port together are written with a colon: 192.168.1.10:8080.

Programs that wait for connections "listen" on an agreed port so that others know where to find them: web servers on 80 and 443, mail on 25, and so on. Your own browser uses a random high port for its side of each conversation.

The numbers fall into three bands. 0 to 1023 are the well-known ports, registered for the classic services. 1024 to 49151 are registered for particular products. 49152 to 65535 are free for temporary use. The registrations are kept by IANA, the body that also coordinates IP addresses. A program can be set to listen on a different port from its usual one, so the list below shows convention, not a guarantee.

TCP and UDP are the two ways of carrying data. TCP checks that everything arrives in order (web pages, mail, files). UDP sends without checking, which is quicker (calls, games, DNS questions). The same number is a different port in each.

Open, closed and forwarded ports

A port is open when a program is listening on it and nothing in between blocks the way. It is closed when nothing is listening. A firewall can also silently drop traffic to a port, which makes it look as if nothing is there at all.

Your home router blocks connections coming in from the internet on every port unless you tell it otherwise. Port forwarding is that instruction: "send anything arriving on port 25565 to the computer at 192.168.1.20". It is needed for hosting a game server or reaching a recorder from outside, and it does not work behind carrier-grade NAT.

Ports and safety

  • An open port is only as safe as the program behind it. Forward a port only for something you run on purpose and keep updated.
  • Never expose 445 (Windows file sharing), 23 (Telnet) or 3389 (Remote Desktop) directly to the internet. Automated attacks try them on every address, all day. Use a VPN into your network for remote access.
  • Turn off UPnP in the router if you do not need it. It lets any program or device in the house open ports by itself.
  • Changing a service to an unusual port cuts down noise from automated scans but is not protection in itself.

Ports on your own computer

Addresses such as localhost:3000 or 127.0.0.1:8080 use ports too, on your own machine only. See 127.0.0.1 and localhost. To see what is listening on Windows, open Command Prompt and run:

netstat -an

Lines marked LISTENING show ports with a program waiting on them.

What port does HTTPS use?

443. Plain HTTP uses 80. Browsers add these by themselves, which is why you never type them.

Is it dangerous to have open ports?

Outgoing connections from your devices are normal and safe. The risk is in ports open to incoming connections from the internet, where an outdated or badly secured program is listening.

How many ports are there?

65,536 for TCP and the same again for UDP, numbered 0 to 65,535.
