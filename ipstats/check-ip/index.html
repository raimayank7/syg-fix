Is this IP address public or private?

Type any IPv4 or IPv6 address. The checker says whether it is valid and what kind of address it is.

What the checker tells you

For any address you type, it answers three questions.

  1. Is it a valid address? An IPv4 address needs exactly four numbers from 0 to 255. An IPv6 address needs hex groups and colons in the right pattern. A typing slip such as 192.168.1.256 or the letter l in place of the digit 1 is caught here.
  2. What kind is it? Public, private, or one of the special kinds below.
  3. Can it be reached from the internet? Only public addresses can.

The check uses the fixed list of ranges that the internet's standards set aside, so it runs entirely in your browser. It does not look up who owns a public address or where it is, and it does not contact the address.

When this is useful

  • Your router's WAN address: if it turns out to be private or shared, you are behind carrier-grade NAT and port forwarding will not work.
  • An address in a log or an email header: a private address there tells you about the sender's inner network only, not where they are.
  • A device showing 169.254.x.x: it failed to get an address. Restart the router and reconnect.
  • Homework and exam questions on address classes and ranges.
  • Setting an address by hand: check that what you are about to type is valid and in a private range.

Tap the sample buttons above the Check button to see one of each kind.

Why is 172.32.0.1 public when 172.16.0.1 is private?

Only 172.16.0.0 to 172.31.255.255 is private. The rest of the 172 block is ordinary public space.

Is 192.168.1.1 dangerous to share?

No. It is a private address used by millions of routers and means nothing outside your own network.

Can the checker tell me who owns a public address?

No. That needs a look-up in the registries' "whois" records, which this page does not do. It only classifies the address.
