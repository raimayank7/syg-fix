IP and network tools

Small tools for addresses, networks and connections. They run in your browser and store nothing.

  • My IP Your public IP address and what your browser tells every website, shown only to you
  • Subnet calculator Type an address and choose a prefix
  • Check an IP Type any IPv4 or IPv6 address
  • IP converter Type an IPv4 address, a whole number or a hex value
  • IPv6 tool Paste an IPv6 address in any form
  • Download time Type a file size and a speed to see how long the transfer takes, and how much data that speed moves in a minute and an hour
  • User agent The user agent is one line of text your browser sends with every request
  • Screen size Your screen size, real pixels, pixel ratio and the page area of this window, measured live by your browser
  • Response test A quick test of how fast your connection responds
  • CIDR table Every IPv4 prefix length with its mask, the number of addresses in the block and how many can be given to devices
  • Port numbers The port numbers you are most likely to meet, with the service that normally uses each
  • HTTP codes Every time a browser asks for a page, the server answers with a three-digit code

How these tools work

Every tool on this page runs inside your own browser. When you type an address into the subnet calculator or the checker, the arithmetic is done by your device; nothing is sent to a server, so nothing can be logged or stored. Most tools keep working without a connection once the page has loaded. The two exceptions are the home page, which has to ask an outside service for your public address because your device does not know it, and the response test, which times small requests to this site.

Which tool do I need?

  • "What is my IP?" The home page shows your public IPv4 and IPv6 addresses and the details your browser shares.
  • "Is this address private or public?" Use Check an IP. It also catches mistyped addresses.
  • Homework, exams or setting up a network: the subnet calculator, the CIDR table and the IP converter show the working, not just the answer.
  • A long IPv6 address to tidy or compare: the IPv6 tool.
  • "How long will this download take?" The download time calculator, which also turns Mbps into megabytes per second.
  • "Is my connection laggy?" The response test times ten small requests and reports the delay and its steadiness.
  • Reporting a problem to a website or developer: your user agent and your screen size are the two details they ask for first.
  • Looking something up: port numbers and HTTP status codes are searchable lists in plain words.

A note on accuracy

The address arithmetic is tested against known answers. Readings that come from your browser, such as connection speed or memory, are rough estimates that browsers deliberately blur for privacy; each page says so where it applies. If a result looks wrong, please tell us through the contact page with the value you typed.

Do I need to install anything?

No. The tools are web pages. They work in any modern browser on a phone or a computer.

Are the tools free?

Yes, with no login and no limit.
