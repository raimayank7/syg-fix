How to use it

  1. Type a word. The search looks at icon names first, then at their tags, and every word you type must match.
  2. Click an icon to see its code. Set the size and the stroke width, give it a label if it carries meaning, and choose a colour if it should not follow the text colour.
  3. Copy the SVG into your page, or download it as an SVG or a PNG file.
