How to learn subnetting

Start with "What is subnetting", then "How to subnet step by step", and practise with the calculator: work out the answer by hand first, then type the address to check. The cheat sheet of prefixes from /8 to /32 is worth keeping beside you.

Frequently asked questions

Are the calculators accurate?

We compared them with Python's ipaddress module on 1,400 random cases and found no differences.

Does the site store the addresses I type?

No. The calculators run in your browser. The address in the page's link is only there so that you can share a result.

Why do some ports show several registered names?

The IANA registry sometimes lists more than one service for the same number. The pages show all of them.
