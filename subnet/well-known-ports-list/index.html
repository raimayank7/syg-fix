Reading the list

The system ports run from 0 to 1023 and are the numbers that standard services use. Many entries are old protocols that you will never meet. The ones that matter today are in the topic pages: web, email, remote access, file transfer, databases and network services. "(+N more)" means the registry lists N more services for the same number; open the port page or search on the port numbers page to see them.

A registration shows what a number was reserved for. It does not prove what is running on a port, and a service can use any port you configure. See what is a port number.

This is an independent guide. It is not connected with IANA, the IETF or any network equipment maker. Address and port data come from the IANA registries as fetched on 14 November 2026; RFC texts were read from rfc-editor.org. Check the originals for anything you rely on.
