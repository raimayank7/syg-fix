How to read the table

The prefix is the number of fixed bits. Each step down in the table doubles the number of addresses. Usable hosts are the addresses minus two (the network and broadcast addresses), except for /31 (2 hosts, RFC 3021) and /32 (one host). The wildcard mask is the subnet mask turned upside down, used by some router commands.

Numbers worth memorising

/24 is 256 addresses and 254 hosts. Every bit you add halves the block: /25 has 128, /26 has 64, /27 has 32, /28 has 16, /29 has 8 and /30 has 4. Going the other way, /23 is two /24 blocks and /16 is 256 of them. The table was generated with Python's ipaddress module. Use the mask converter for a single prefix, or the hosts guide for the formula.
