How to use the tables

"Forwardable" says whether a router may pass packets from or to the block beyond its own network, and "Globally reachable" says whether the block is meant to be reachable from the public internet. Blocks marked False for both are internal-only. If an address from one of these blocks shows up as the source of a request from the internet, it is probably forged.

Not in these tables

Multicast ranges (224.0.0.0/4 in IPv4, ff00::/8 in IPv6) are allocated through other registries. The calculators on this site label multicast separately. For private addresses and NAT, see the page on private IP ranges.
