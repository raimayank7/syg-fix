Subnet and Ports

Port numbers

Search the IANA service name and port number registry by number or by name.

Type a port number (443) or a name (ssh, mysql, mail).

Guides by topic

  • Web ports: 80, 443 and the usual alternatives
  • Email ports: 25, 465, 587, 110, 143, 993 and 995
  • Remote access ports: SSH 22, Telnet 23, RDP 3389 and VNC 5900
  • File transfer ports: FTP 20 and 21, SFTP, FTPS and others
  • Database ports: MySQL 3306, PostgreSQL 5432, MongoDB 27017, Redis 6379 and others
  • Network service ports: DNS 53, DHCP 67 and 68, NTP 123, SNMP 161, LDAP 389

About the data

The search covers 6264 entries (a port with several registered services has several entries) from the IANA registry fetched on 14 November 2026. The list loads when you start typing. Many numbers have no registration at all, and some registered names belong to programs nobody uses any more: a registration shows what a number was reserved for, not what is running on your network. For the meaning of the ranges (system, user, dynamic) read what is a port number.

This is an independent guide. It is not connected with IANA, the IETF or any network equipment maker. Address and port data come from the IANA registries as fetched on 14 November 2026; RFC texts were read from rfc-editor.org. Check the originals for anything you rely on.
