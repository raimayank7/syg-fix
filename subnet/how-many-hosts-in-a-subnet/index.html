Subnet and Ports

How many hosts in a subnet: the formula and a table

Usable hosts = 2 to the power of the host bits, minus 2. The exceptions are /31 and /32.

The formula

An IPv4 address has 32 bits. With a prefix of p, the number of host bits is 32 - p, and the block has 2^(32 - p) addresses. Two of them are reserved in an ordinary subnet: the network address (all host bits zero) and the broadcast address (all host bits one). So:

usable hosts = 2^(32 - p) - 2

For /24: 2^8 = 256 addresses, 254 hosts. For /26: 2^6 = 64 addresses, 62 hosts. For /20: 2^12 = 4,096 addresses, 4,094 hosts.

The exceptions

  • /31: two addresses. RFC 3021 allows both to be used as hosts on a point-to-point link, so there is no network or broadcast address.
  • /32: one address, a single host.
  • /30: four addresses, two hosts: classic for a link between two routers.

Planning with the table

  1. Count the devices now. Add printers, cameras, phones and anything with an address.
  2. Add growth. A rule of thumb is to leave a quarter to a half free.
  3. Add one for the router (the gateway).
  4. Pick the smallest prefix whose usable hosts cover the total.

Cloud networks reserve more

Cloud providers often reserve more addresses in each subnet for their own use (for example for the gateway and DNS). Check your provider's documentation: the usable number can be smaller than the formula.

Common mistakes

  1. Using the total number of addresses as the number of hosts.
  2. Forgetting the gateway.
  3. Choosing a subnet that is exactly big enough. Networks grow.
How many hosts does a /29 have?

2^3 - 2 = 6.

How many addresses does a /22 have?

2^10 = 1,024 addresses and 1,022 usable hosts.
