Blogger SEO checklist from Blogger's own help

Blogger's help gives a short list of search tips. This page turns it into a checklist you can tick off.

1. Let search engines in

Open Settings. Under Privacy, make sure Visible to search engines is on. If it is off, the blog asks not to be listed.

2. Write titles for people and engines

Include the words that say what the post is about. Blogger's help suggests keeping titles under 60 characters, so that they are readable and not cut off in the results. Put the main words first.

3. Use headings

Headings (H2, H3 and so on) tell search engines and readers how a post is organised. In the post editor, highlight the text, open the Paragraph menu and pick a heading level. Use one main title, then H2 for sections, H3 for sub-sections. Do not use headings just to make text big.

4. Describe your images

Click an image in a post and choose Edit. The alt field takes a longer description of what the picture shows (it helps visitors using screen readers and image search). The title field takes a short description. Fill both for pictures that matter.

5. Write a search description

Turn on the search description in Settings under Meta tags, and write a summary for the blog (see that page).

6. Choose clean addresses

Use custom permalinks for important posts, and redirects when addresses change.

7. Hide what should not be listed

Use No index in the post settings for individual pages that should stay out of results, and the robots header tags for groups of pages. Use rel="nofollow" on links you do not vouch for.

8. Tell Google about the blog

Link Google Search Console, submit the sitemap and check the indexing report.

9. Things that matter but are not on Blogger's list

These are general good practice, not Blogger rules: original content that is useful to a reader, pages that load quickly and work on a phone, clear About and Contact pages, links between your own related posts, and a regular schedule. For AdSense, see the eligibility checklist.

Is Blogger bad for SEO?

No. It produces clean pages, sitemaps, feeds and canonical tags (we saw the canonical link on a Blogger post). Results depend mostly on your content.

How long until I rank?

There is no fixed time. New blogs take weeks to months to build visibility.
