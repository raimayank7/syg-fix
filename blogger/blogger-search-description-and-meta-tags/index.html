Blogger search description and meta tags

The search description is the short text that search engines may show under your link. Blogger has a switch for it and a field on every post.

Turn it on

  1. Open Settings.
  2. Find the Meta tags section.
  3. Turn on Enable search description and write a short summary of what your blog is about.

Blogger's help words it as a way to help users choose your blog in search results by writing a summary of what the blog is about.

Write a good description

  • Write one or two sentences, up to about 150 characters, that tell a person what they will find and why it is useful.
  • Use the words people actually search for, but write for a person, not a robot.
  • Do not copy the title. Do not stuff keywords.
  • Make each page's text unique: a description that is the same on every page tells a search engine nothing.

Per post descriptions

If the post editor shows a Search description option in its settings sidebar (it appears when the blog-level search description is on), write a different summary there for each important post. This option is described from experience, not from the help page we read.

What happens when it is empty

Search engines then choose their own text from the page, often the first lines. That is fine for many pages. A careless description is worse than none, so skip it rather than repeat the same sentence everywhere.

A trap on pages

When a page has no description of its own, a theme can fall back on the description of the whole blog, so many pages end up with the same text. If you edit your theme, check what value the page description uses, and fill in the field for pages that matter.

Check what you published

Open the page in your browser, right-click and choose "View page source", and search for name="description". The text there is what search engines read from the page.

Other meta settings

The Basic section of Settings holds the blog title and the description of the blog. These are shown in headers, in feeds and in some search results. Keep them consistent with the meta tag description.

Does the description affect ranking?

Search engines say the description is not a ranking factor, but a clear one gets more clicks, and clicks matter to you.

Why does Google show different text than my description?

Search engines may choose text from the page if they think it matches the search better.
