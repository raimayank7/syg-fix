Blogger settings explained: every section of the Settings page

Most Blogger questions end in a setting. This page walks through the Settings page in order and says what each section controls.

How the page is organised

On the web version of Blogger, open your blog and choose Settings in the left menu. The page is divided into sections. The descriptions below follow Blogger's help page for settings, read on 13 November 2026. Names of menu items can change, so if one is missing, use the search box in your browser to find the words on the page.

The ones that matter most

Privacy: Visible to search engines. If it is off, search engines are told not to list the blog. A new blog that "never appears in Google" often has this switched off.

Posts: maximum posts on the main page changes how many posts the home page shows, which changes its length and loading time.

Meta tags: search description. Blogger lets you write a summary that search engines may show. See the page on search descriptions.

Crawlers and indexing. Custom robots.txt and robots header tags can hide your whole blog if set wrongly. See the two pages on these.

Site feed. If the feed is set to Short, it carries about the first 400 characters of each post. Apps that read the feed (readers, apps, scripts) then receive only that part. Full sends the whole post; None turns the feed off.

Two numbers worth remembering

You can add up to 100 members (authors, administrators, readers) in total. You can enter up to 10 email addresses for comment notifications and for post notifications.

The time zone

The time zone setting decides the times shown on posts and the time used by scheduled posts. Set it right at the beginning, or scheduled posts appear at the wrong hour.

Does hiding comments delete them?

No. Blogger says that choosing "Hide" does not delete existing comments. You can show them again by choosing another option.

What is Mail2Blogger?

It is the "Post using email" feature: a private address that lets you send a post to the blog by email. Anyone who knows the address can post as you, so keep it secret.
