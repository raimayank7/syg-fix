Blogger errors and problems: a troubleshooting checklist

Most Blogger problems have one of five causes: the browser, an extension, bad code, a broken gadget or a wrong setting. Check them in this order.

The general checks

Blogger's help gives this order:

  1. Reload the page.
  2. Update your browser (the page names Chrome 49 and later or Safari 10 and later as the minimum; use current versions).
  3. Try a different browser. If you use Internet Explorer, turn off compatibility mode.
  4. Clear the browser's cache and cookies.
  5. Open a private window. If Blogger works there, remove your extensions or plug-ins, one at a time.
  6. Search the Blogger community forum for your issue.
  7. If you get the error when saving theme or gadget changes, check your code for problems.

Specific problems

The blog is still online after you deleted it. It may take time to disappear completely. Blogger links to a way to remove the cached version.

You cannot delete a post. To delete a post someone else wrote, ask the blog administrator. If the blog has only one post, create another and then delete the old one, or delete the blog.

You cannot upload pictures. Turn off the popup blocker, or add Blogger.com as an approved page. In the Add Images box, click Select.

The sidebar moves to the bottom of the page. Check whether your content is too wide for its column: a wide picture, table or embedded video pushes the sidebar down. Set images to max-width: 100%.

A gadget is broken. In Layout, click Edit on the gadget and Remove.

The blog is blank or shows code. Open Theme, click Edit HTML, check the code and fix it, or choose a new theme, then click Save. If the code looks fine, it may be an encoding problem: set the browser's text encoding to auto-detect or Unicode (UTF-8). In Chrome and Edge you cannot change the encoding setting.

Messages with "bx"

Blogger errors often look like bX-abc123. The code only helps the support team; the fix is the same list as above. If it continues, use Help and feedback, then Send feedback, in the top right of the dashboard.

Problems in the theme code

  • A missing closing tag or an unescaped < or & breaks the XML. Use an XML validator on a copy of the theme.
  • Do not paste curly quotes into code (copy from a plain text editor).
  • Undo the last change first. Most theme breaks come from the last edit you made.

When you are stuck

Restore a theme backup (see the backup page). Then repeat your changes one by one. Describe the problem to others with the exact words of the error, the page address, the browser and what you changed last.

Why does Blogger work on my phone but not on my computer?

Probably an extension or cached data on the computer. Try a private window.

Where do I report a bug?

In the dashboard: Help and feedback, then Send feedback.
