ads.txt on Blogger: what it is and how to set it up

ads.txt is a plain file that lists who is allowed to sell ads on your site. Blogger has a field for it.

What ads.txt is

Authorized Digital Sellers, or ads.txt, is an initiative of the IAB Tech Lab. The file lists the companies you authorise to sell ads on your site, which helps stop counterfeit inventory. Google's AdSense guide says that using ads.txt is not mandatory but is highly recommended. An alert appears in your AdSense account if there is a problem.

The AdSense line

For AdSense the file contains one line with your own publisher ID:

google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0

Replace pub-0000000000000000 with your real publisher ID. In AdSense, the alert or the Sites page offers an "Ads.txt snippet" with the exact line to copy. If you also use another ad network, add the line that network gives you on a new line.

On Blogger

Blogger's help says that if the blog is monetised with third-party providers or you have integrated AdSense by hand, you need to set up the content of ads.txt manually:

  1. Open Settings.
  2. Under Monetization, turn on Enable custom ads.txt.
  3. Click Custom ads.txt.
  4. Paste the lines from your provider and click Save.

If you set up AdSense through the Blogger Earnings route, Blogger can handle the file itself; use the custom field when you add other networks or your own code.

Check it

Open https://your-blog-address/ads.txt in a private window. The text you saved must show. Google says that if the file shows in the browser, AdSense will probably find it. The file must sit at the root of the site (example.com/ads.txt), which on Blogger it does automatically. We also fetched the file of a Blogger-hosted blog on 13 November 2026 and it showed one Google line in this format.

After the change

It can take a few days for AdSense to show the change, and up to a month on sites with few ad requests, according to Google's guide. You can ask AdSense to recheck in the Sites page.

Common mistakes

  1. Typing the publisher ID wrongly. Copy from AdSense.
  2. Adding spaces, extra punctuation or text that is not a valid ads.txt line.
  3. Using the wrong address: with a custom domain the file is read from the domain you use, not the blogspot address.
  4. Forgetting that each network needs its own line.
Is ads.txt an SEO file?

No. It is about advertising only.

What does DIRECT mean?

It says that you, the publisher, have a direct relationship with that ad system. The long code at the end is that company's identifier.
