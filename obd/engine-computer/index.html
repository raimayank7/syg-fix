P0600 to P0607

Engine computer (ECM) internal faults

Fault codes P0600 to P0607 explained in plain words: what the car is telling you, how serious it is and what to check first.

How serious: HighThis can damage the engine or gearbox, or leave you stranded. Stop if the car feels unsafe, and have it checked now.

What it means

The engine computer checks its own memory and processor all the time. These codes mean it found an error inside itself. Sometimes the cause is outside the unit: poor power supply or earth, or a failed software update.

Bank 1 is the side of the engine that has cylinder 1. Sensor 1 is before the catalytic converter and sensor 2 is after it. More terms explained.

What you may notice

  • Engine will not start, or stalls
  • Erratic running or gear changes
  • Many warning lights
  • Sometimes no symptom

Common causes

Most likely first:

  • Low or unstable battery voltage
  • Poor earth connections to the computer
  • Water getting into the computer or its connectors
  • Corrupted software after an interrupted update
  • A failed computer

What to check first

  • Have the battery, charging system and earth straps checked first
  • Ask a dealer whether a software update exists for this fault
  • Replacement computers usually need coding to the car, so this is a specialist job

Have a mechanic confirm. A fault code tells you which system reported a problem, not which part has failed. The same code can have several causes, and they differ between car models. Use this page to understand the code, then have a qualified mechanic test the car before any part is replaced.

After the repair

Once the cause is fixed, the code can be cleared with a scan tool, or the warning light goes out by itself after several trips without the fault. Clearing a code without fixing the cause only hides it for a while. More about clearing codes.

Related codes

Engine overheating or overspeed (P0217), Fuel level sensor (P0460), Radiator cooling fan circuit (P0480), Vehicle speed sensor (P0500), Idle speed control (P0505), Brake pedal switch (P0504), Engine oil pressure sensor (P0520), Air conditioning pressure sensor (P0530). All codes.
