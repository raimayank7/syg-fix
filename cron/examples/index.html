How to adapt an example

Change one field at a time and watch the meaning change. To move a daily job to another time, change the first two numbers (minute, then hour). To limit it to some days, change the last field. To limit it to some months, change the field before it. The meaning column says "every day" only when you left the day fields as stars, so it is a good check that you did not set a day rule by accident.

The examples are for the five-field form. For Quartz, paste an example into the tool and read the Quartz form it prints. If you meant a schedule that is not here, the tool accepts anything cron can say, and the pages on the day fields and on step values explain the cases that do not behave like their name.
