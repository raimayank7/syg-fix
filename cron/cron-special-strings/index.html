Cron shortcuts: @daily, @weekly, @reboot and the others

Instead of five fields, many cron programs accept one word that starts with an at sign.

The list

The cronie manual lists these as replacements for the first five fields. Kubernetes lists the same ones, plus the name @midnight.

ShortcutMeaningSame as
@rebootOnce, after the machine startsnot a time
@yearly or @annuallyOnce a year0 0 1 1 *
@monthlyOnce a month0 0 1 * *
@weeklyOnce a week, Sunday0 0 * * 0
@daily (Kubernetes also @midnight)Once a day0 0 * * *
@hourlyOnce an hour0 * * * *

Where they work

  • A Linux or Mac crontab: yes (these come from the Vixie cron family).
  • Kubernetes CronJob: yes, its documentation has a table of them. It does not list @reboot, which makes no sense for a cluster.
  • GitHub Actions: its page documents the five fields and the operators * , - / only, so write the fields.
  • Quartz: no. The tutorial lists only the seven fields.
  • Spring's own CronExpression (six fields, seconds first): yes. Its documentation lists @yearly (or @annually) as 0 0 0 1 1 *, @daily (or @midnight) as 0 0 0 * * *, and the others in the same way.

The tool on the home page accepts the shortcuts for the Unix and Kubernetes types and shows the five fields behind them.

@reboot

@reboot runs once when the cron service starts, which is usually when the machine boots. It is useful for starting a small background program after a restart. It has no time of day, so there is nothing for the tool to list. Mind that it also runs when only the cron service restarts, depending on the system, and that the network may not be ready yet, so a script that needs the internet should wait for it.

Reading them well

The weekly shortcut is Sunday at midnight, which is the moment between Saturday and Sunday. If you thought of it as "start of the week" in a country where the week starts on Monday, you need 0 0 * * 1. In the same way, @monthly runs on the 1st at midnight and @yearly on 1 January at midnight, all in the server's time zone.

Is @midnight the same as @daily?

Kubernetes lists both as 0 0 * * *. The cronie manual we read lists @daily only, so use @daily on Linux.

Can I use @daily in a Quartz expression?

No. Write all fields: 0 0 0 * * ?. (Spring's own scheduler is different and does accept @daily.)
