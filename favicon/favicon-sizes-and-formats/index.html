Favicon sizes and formats

A favicon is the small picture in a browser tab, in bookmarks and in search results.

What Google says

For the icon to appear in Google Search results, Google's documentation requires that the favicon is a square (1:1) of at least 8 × 8 pixels, and recommends one larger than 48 × 48 pixels so that it looks good on various surfaces. It supports the formats BMP, GIF, ICO, PNG, JPEG, PPM and TIFF. The address of the favicon must be stable, so do not change it often. You tell Google about it with a link tag in the head of your home page: <link rel="icon" href="/path/to/favicon.ico">. Google also accepts shortcut icon and apple-touch-icon as rel values.

What Apple says

Apple's archived Safari documentation says that to give an iOS home-screen icon for the whole site, you put a PNG file named apple-touch-icon.png in the root folder, or you add <link rel="apple-touch-icon" href="..."> to a page. To support several devices, give each link a sizes attribute. The page lists 152 × 152 (iPad), 167 × 167 (iPad retina) and 180 × 180 (iPhone retina), and says that the most suitable size for the device is used. It points to the iOS Human Interface Guidelines for current sizes: because the page is archived, check them.

The minimal tags

<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">

Design tips

  1. Use a simple shape with a strong contrast. Fine detail disappears at 16 pixels.
  2. Test it small: look at the 16 pixel preview.
  3. A single letter or a bold mark often works better than a full logo.
  4. Keep the same file address once it is in use.
Do I still need favicon.ico?

Browsers ask for /favicon.ico on their own if no link tag is found, so a file there is a safe default.

Can I use SVG?

Browsers can show SVG icons with <link rel="icon" type="image/svg+xml" href="...">, but Google's list of supported formats for search results does not include SVG, so keep a PNG or ICO too.
