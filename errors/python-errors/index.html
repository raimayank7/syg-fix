Python error messages are usually clear once you know how to read them: the last line names the type of error and gives a message, and the lines above point to the place in your code. Every page below shows a small program that makes the error, the exact text Python printed when we ran it on 3.14.10, and a corrected version that was run too.

If you are not sure where to start, read how to read a Python traceback first. Then pick the error you see, or paste it into the box on the home page.
