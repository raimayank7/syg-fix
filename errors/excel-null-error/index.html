Excel #NULL! error

A plain-words explanation of this Excel message: what it means, the usual causes, and the steps that fix it.

The message#NULL!

Make the error yourself

Typed into Microsoft Excel 16.0 build 20326. This is the smallest example we could find that shows it.

CellWhat was typed
A11
A22
A33
C14
C25
C36
E1=SUM(A1:A3 C1:C3)

The cell looked at: E1.

Excel shows: #NULL!

Why it happens

In a formula, a space between two ranges is an operator: it means "the cells that both ranges have in common" (the intersection). When the two ranges do not overlap, the result is empty and Excel shows #NULL!. In the example the space was typed where a comma belongs. It is nearly always a typing mistake: a space instead of a comma, or a missing colon in a range such as A1 A3.

How to fix it

  1. Look at the formula bar. Find a space between two ranges.
  2. Replace it with a comma if you want both ranges (SUM(A1:A3,C1:C3)), or with a colon if you want one range (A1:C3).
  3. If your computer uses semicolons as list separators, use a semicolon instead of the comma.

The corrected version

CellWhat was typed
A11
A22
A33
C14
C25
C36
E1=SUM(A1:A3,C1:C3)

The cell looked at: E1.

Excel shows: 21

How to avoid it

Do not type spaces inside references. Click the cells with the mouse so that Excel writes the separators for you.

Questions

Is the intersection operator ever useful?

Yes, with named ranges: =Sales Q1 returns the cell where the named row and column cross.
