JavaScript errors appear in the browser console, and the words depend on the browser. The pages below use the messages of Google Chrome (the same words are used by Microsoft Edge and Node.js); Firefox and Safari word several of them differently, and the paste box on the home page knows some of those wordings. Each example was run as a real web page in Chrome, and the message shown is the one that Chrome printed.

Start with how to read a JavaScript error in the console if you have not used the developer tools before.
