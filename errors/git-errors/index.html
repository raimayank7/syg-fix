Git messages are long and look alarming, but most of them say one simple thing and print the command that fixes it. The pages below show a short sequence of commands that makes the message, the exact text Git printed on Git 2.56.0.windows.4, and the commands that fix it. The examples use throw-away repositories, so you can repeat them safely in a practice folder.

If you see a message that is not here, copy its first line into the box on the home page.
