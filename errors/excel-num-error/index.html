Excel #NUM! error

A plain-words explanation of this Excel message: what it means, the usual causes, and the steps that fix it.

The message#NUM!

Make the error yourself

Typed into Microsoft Excel 16.0 build 20326. This is the smallest example we could find that shows it.

CellWhat was typed
A1-4
B1=SQRT(A1)

The cell looked at: B1.

Excel shows: #NUM!

Why it happens

#NUM! means a number is not acceptable for the function or the result is too large or too small for Excel. The example takes the square root of a negative number, which has no real answer. Other causes: functions that find an answer by repeated trials (IRR, RATE, XIRR) and cannot find one, numbers beyond about 1E+308, LARGE or SMALL asked for a position that does not exist, and a date outside the range that Excel supports.

How to fix it

  1. Check the arguments of the function: do negative numbers, zero or very large numbers make the function impossible?
  2. Test them first: IF(A1<0, "...", SQRT(A1)) or SQRT(ABS(A1)) if the sign does not matter.
  3. For IRR and RATE, give a guess value as the last argument, and check that the cash flows have at least one positive and one negative number.
  4. Make sure that dates and times are real dates, not text.

The corrected version

CellWhat was typed
A1-4
B1=IF(A1<0,"negative number",SQRT(A1))

The cell looked at: B1.

Excel shows: negative number

How to avoid it

Validate inputs for functions that have a limited range, and give iterative functions a good starting guess.

Questions

Why does IRR give #NUM!?

Excel tries up to a set number of times to find a rate. If the cash flows have only positive or only negative values, no rate exists.
