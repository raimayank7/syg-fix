Excel #N/A error

A plain-words explanation of this Excel message: what it means, the usual causes, and the steps that fix it.

The message#N/A

Make the error yourself

Typed into Microsoft Excel 16.0 build 20326. This is the smallest example we could find that shows it.

CellWhat was typed
A1Apple
B140
A2Banana
B225
D1Mango
E1=VLOOKUP(D1,A1:B2,2,FALSE)

The cell looked at: E1.

Excel shows: #N/A

Why it happens

#N/A means "not available": a lookup function (VLOOKUP, HLOOKUP, MATCH, XLOOKUP) did not find the value it was asked for. In the example "Mango" is not in the list. The usual reasons for a value that "is there but not found": extra spaces at the end of the text, a number stored as text on one side (123 against "123"), different spellings or capital-letter-only differences in the data, a lookup range that does not include the value, and an exact-match setting (FALSE or 0) that correctly refuses an inexact match.

How to fix it

  1. Check the value that you are looking up and the list. Is it really present?
  2. Remove hidden spaces with TRIM: =VLOOKUP(TRIM(D1),A1:B2,2,FALSE).
  3. Check for numbers stored as text: left-aligned numbers and a green triangle in the corner are signs. Convert them with Data > Text to Columns > Finish, or VALUE().
  4. For a friendly message use IFNA(formula,"not found"), which only catches #N/A and leaves other errors visible.
  5. Make sure the lookup range starts in the column that contains the search value (for VLOOKUP, the first column).

The corrected version

CellWhat was typed
A1Apple
B140
A2Banana
B225
D1Mango
E1=IFNA(VLOOKUP(D1,A1:B2,2,FALSE),"not in list")

The cell looked at: E1.

Excel shows: not in list

How to avoid it

Clean the data once (trim spaces, make types consistent) and prefer IFNA over IFERROR so that real mistakes are not hidden.

Questions

What is the difference between IFNA and IFERROR?

IFNA catches only #N/A. IFERROR catches every error type, which can hide typing mistakes in the formula.
