The item-shape checker

n8n passes data between nodes as an array of objects, each wrapping its data under the key json. Paste JSON above to see whether it has that shape, and wrap it if it does not. It checks the shape described in the documentation; it does not run n8n and sends nothing anywhere.

Is this a course on a particular product?

It uses n8n's documentation as its source, because that documentation is open and specific. The ideas (triggers, actions, items, error handling) carry over to other tools.
