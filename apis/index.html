APIs for India Guides

What is here

Eleven free APIs that need no key and answer browser requests. Every page has the request in curl, Python and JavaScript, a real answer, a box to try it and a summary of the terms.

How we chose

  1. No key, no sign-up.
  2. It answered from Chrome on a page of another site (CORS).
  3. It gave the same successful answer with curl, Python and Node.js.
  4. We could read its terms.

Before you build on one

Read the terms on the API's own page, cache the answers, and have a plan for when the service is slow or gone.

Are these APIs reliable?

No promise. Free services can change or stop. The guides explain how to be polite and how to cope.

Can I use them in a commercial site?

Check each one. For example Open-Meteo's free tier is for non-commercial use only.

This is an independent directory. It is not connected with any of the services listed. Each address was called on 14 November 2026 with curl, Python, Node.js and Chrome (from a page on another site), and the answer shown is a real one. APIs change: check the service's own page before you depend on it.
