World Bank indicators

Thousands of development indicators for countries and years: population, income, health, education.

Address that will be called:

What it gives you

Thousands of development indicators for countries and years: population, income, health, education. The answer is a two-part list: the first part describes the page (how many results), the second holds the values by year.

Terms and limits

The World Bank's terms for using its datasets give permission subject to attribution to the World Bank Group (the terms page we read says the licence rights are conditioned on proper attribution): read the current terms before you republish data.

_Read on 14 November 2026 from worldbank.org, terms of use for datasets._

Good habits

  1. Cache answers that do not change often.
  2. Handle errors: the service may be busy or down.
  3. Give credit where the terms ask for it.
  4. Do not put secret keys into a web page: this API needs none, but many others do.

The same request in code

curl

curl -L "https://api.worldbank.org/v2/country/IN/indicator/SP.POP.TOTL?format=json&per_page=3"

Python

import json, urllib.request

with urllib.request.urlopen("https://api.worldbank.org/v2/country/IN/indicator/SP.POP.TOTL?format=json&per_page=3") as r:
    data = json.load(r)
print(data[0])

JavaScript (browser or Node.js)

const res = await fetch("https://api.worldbank.org/v2/country/IN/indicator/SP.POP.TOTL?format=json&per_page=3");
const data = await res.json();
console.log(data[0]);
