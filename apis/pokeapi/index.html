PokeAPI

A large, well-structured API of Pokemon data.

Address that will be called:

What it gives you

A large, well-structured API of Pokemon data. It is widely used to learn APIs because its answers are rich and nested, with links to related resources.

Terms and limits

PokeAPI's fair use policy says to cache resources locally whenever you request them and to be friendly to other developers, and lists policies that limit abuse (for example, a restriction on non-GET methods). Pokemon names and data belong to their owners: use it for learning.

_Read on 14 November 2026 from pokeapi.co/docs/v2._

Good habits

  1. Cache answers that do not change often.
  2. Handle errors: the service may be busy or down.
  3. Give credit where the terms ask for it.
  4. Do not put secret keys into a web page: this API needs none, but many others do.

The same request in code

curl

curl -L "https://pokeapi.co/api/v2/pokemon/pikachu"

Python

import json, urllib.request

with urllib.request.urlopen("https://pokeapi.co/api/v2/pokemon/pikachu") as r:
    data = json.load(r)
print(data['name'])

JavaScript (browser or Node.js)

const res = await fetch("https://pokeapi.co/api/v2/pokemon/pikachu");
const data = await res.json();
console.log(data.name);
