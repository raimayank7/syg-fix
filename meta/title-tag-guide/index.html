How to write a title tag

The title is the first thing a person sees in a search result and the name of the browser tab.

What Google says

Google's page on title links says to make sure that every page has a title specified in the <title> element, to write descriptive and concise text, and to avoid vague titles such as "Home" or "Profile" and also unnecessarily long ones. It adds that there is no limit on how long a title can be, but the title link is truncated in results as needed, typically to fit the device width. It also warns against keyword stuffing, which means repeating the same words.

Rules that follow

  1. One title per page, different on every page. Two pages with the same title confuse readers and tools.
  2. Put the main thing first. If the end is cut, the beginning still tells the story.
  3. Say what the page is, not only its type: "Wedding invitation wording in Hindi" beats "Invitations".
  4. Add the site name at the end if you like, after a separator such as a vertical bar.
  5. Match the page. The heading on the page and the title should agree.

Search engines may change it

Google says it uses a number of different sources to determine the title link automatically, and that you can state your preference by following its best practices. One of them is to make the main title distinctive and prominent on the page, for example in the first visible <h1> element.

How many characters should a title have?

There is no official limit. Many sites keep titles under about 60 to 70 characters so that most of it is visible, which is a habit and not a rule.

Is the title the same as the H1?

They can differ, but they should describe the same page.
