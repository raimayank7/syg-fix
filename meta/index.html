Guides

What the tools do

  1. The meta tag generator writes the title, description, canonical, robots and Open Graph tags for a page and checks them.
  2. The JSON-LD generator writes schema.org markup for five common types.
  3. The sitemap generator turns a list of addresses into a valid sitemap.xml.

A short plan for a small site

  1. Give every page its own title and description.
  2. Add a canonical link with the full address of the page.
  3. Add Open Graph tags with an image so shared links look good.
  4. Make a sitemap and submit it in Search Console.
  5. Use noindex only for pages that should not appear in search.
Do I need all of this?

No. Titles, descriptions and a sitemap are the basics. The rest depends on your site.

Is it safe to paste my page details here?

Yes. The tools run in your browser and send nothing.
