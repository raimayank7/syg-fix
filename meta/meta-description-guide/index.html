How to write a meta description

The description is a summary of the page that search engines may show under the title.

What Google says

Google's snippet documentation says that snippets are created from the page content, and that it may use the meta description when it describes the page better than other parts of the content. There is no limit on how long a meta description can be, but the snippet is truncated in results as needed, typically to fit the device width. For content systems such as Wix, WordPress or Blogger, the page says to use the settings of the system if you cannot or do not want to edit the HTML directly.

Writing one

  1. Summarize the page in one or two sentences. What will the reader get?
  2. Use plain words that match what people would search for, but write for people first.
  3. Do not copy the first lines of the page: a description that adds something is more useful.
  4. Keep it different on every page.
  5. Do not promise what the page does not give.

An example

For a page that explains cron schedules: "Type a cron expression and see it in plain English with the next ten run times. Examples for every minute, every hour, weekdays and month end."

In Blogger

Blogger has a search description setting for each post and page, and for the whole blog in Settings. Use it for each post: if you leave it empty, search engines write their own text.

Is a missing description a problem?

No error follows. The search engine writes its own snippet from the page. A good description gives you more control.

Does Google always use my description?

No. It may use other text if that matches the search better.
