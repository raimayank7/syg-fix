Meta tag, Open Graph and canonical generator

Fill in the page details. The tags appear below, ready to paste into the head of the page, with notes on common mistakes.

What the generator writes

  1. The <title> and the description meta tag.
  2. A canonical link, which names the preferred address of the page.
  3. A robots meta tag when you tick noindex, nofollow or a snippet rule.
  4. Open Graph tags (og:title, og:type, og:image, og:url and more) that apps such as WhatsApp use to build a link preview.
  5. Twitter card tags, which some sites and apps read for link previews.

Characters such as quotes, & and < are escaped, so a title like Tom & Jerry "Fan Club" does not break the tag. We tested this by reading the generated tags back with an HTML parser: the values came back exactly as typed.

About the checks

The checks come from the Google Search Central pages on title links, snippets, robots meta tags and canonical addresses. Google states that there is no limit on the length of a title or a description, and that the text shown in results is cut to fit the screen width. So the tool gives a note on length and not a hard limit.

Where to put the tags

Inside the <head> of every page. In Blogger, use Theme, then Edit HTML, and put the tags in the head section. Many content systems have a field for the title and description, and it is better to use that field than to paste tags by hand.

Does a meta description improve ranking?

Google's page on snippets says a description can be used for the snippet when it describes the page better than the page text. It does not call it a ranking factor.

Do I need Twitter card tags?

They are optional. Check the current documentation of the site or app where you expect the preview: we could not read X's documentation on 14 November 2026, so we do not state rules for it.
