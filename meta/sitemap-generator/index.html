Sitemap.xml generator

Paste one address per line. The tool writes a sitemap in the standard format and lists any lines it could not use.

How to use it

  1. Paste the full addresses of the pages you want search engines to find, one per line, each starting with https:// or http://.
  2. Optionally choose a date for lastmod, the day the pages last changed. Use it only when it is true.
  3. Download sitemap.xml, put it in the root of your site and tell search engines where it is (Search Console, or a Sitemap: line in robots.txt).

What it checks

  • The file is written as UTF-8 XML with the standard namespace, and special characters such as & in an address are escaped (&amp;), as the protocol requires.
  • Lines that are not full addresses, and duplicates, are skipped and listed.
  • A sitemap file may hold at most 50,000 addresses and be at most 50 MB uncompressed. The tool keeps the first 50,000 and tells you to split the rest into more files.

We tested it by parsing the output with Python's XML parser for a list with special characters, bad lines and duplicates, and for a list of 50,010 addresses.

Do I have to list every page?

No. A sitemap helps search engines discover pages. Pages that are linked from other pages are usually found anyway.

Should I list pages marked noindex?

No. A sitemap should list the addresses you want to be found.
