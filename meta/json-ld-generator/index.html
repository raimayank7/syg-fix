Meta Tags and Schema

JSON-LD structured data generator

Choose a type, fill in what is really on your page, and copy the script. The names of all properties come from the schema.org vocabulary.

What it does

The generator writes a <script type="application/ld+json"> block. JSON-LD is the format Google recommends for structured data in most cases. The five types here are Article (with BlogPosting and NewsArticle), LocalBusiness (with common subtypes such as Restaurant or Store), Product, BreadcrumbList and Organization.

How it was tested

We generated markup for each type with every field filled and checked it with a script: the JSON is valid, every type exists in the schema.org vocabulary (version read on 14 November 2026), and every property is one that schema.org defines for that type or for a type it inherits from. The script also proved that it catches a wrong property: it rejected openingHours on a Product and an invented property name. A character such as < inside a text is written as \u003c, so that it cannot close the script tag early.

What valid markup does not do

Valid markup is not a promise of a special search result. Google says that it does not guarantee the feature will show, and that its own documentation, not schema.org, is the reference for what is used in Search. Mark up only what a visitor can see on the page. Read the guide on structured data for what changed with FAQ markup.

Where do I paste the script?

Anywhere in the head or the body of the page. Google's introduction to structured data says JSON-LD may be placed in either.

Does the tool send my data anywhere?

No. Everything runs in your browser.
