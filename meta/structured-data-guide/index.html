Structured data and rich results

Structured data labels the parts of a page for programs. It does not decide what a search engine shows.

What it is

Structured data is extra information, in a fixed format, that says what the page is about: an article with an author and a date, a business with an address, a product with a price. Most of it uses the vocabulary of schema.org. Google says there are three formats that are equally fine, as long as the markup is valid and properly implemented, and that JSON-LD is recommended because it is usually the easiest to maintain. JSON-LD sits in a script tag and is not mixed into the visible text.

What it can and cannot do

Google's introduction says structured data can help it understand the page, and that for some types a page can become eligible for an enhanced display in results. It also says that Google's own documentation, not schema.org, is the definitive guide for Google Search behaviour, and that it is more important to give fewer but complete and accurate properties than every property with bad data. Markup is never a promise of a special display.

FAQ markup no longer gives a rich result

A change log of Google Search Central, read on 14 November 2026, records that the documentation for the FAQ rich result was removed because the feature is no longer shown in Google Search results (announced in May 2026). If an older guide tells you to add FAQ markup for a rich result, it is out of date. You can still write questions and answers for your readers in the page itself. This is a reminder that supported types change: check the current Google documentation for any type before you count on it.

Rules to follow

  1. Mark up only what is on the page and visible to the reader.
  2. Keep it accurate: wrong prices or ratings can cause problems.
  3. Test the JSON with a validator, and check the names of properties against schema.org.
  4. Use the generator on this site for the common types: it was checked against the schema.org vocabulary.
Is a rich result guaranteed if my markup is valid?

No. Valid markup only makes a page eligible, and search engines decide.

Where can I check my markup?

Google offers a Rich Results Test and the Schema Markup Validator. We did not run them for this guide.
