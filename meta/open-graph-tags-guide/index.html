Open Graph tags for link previews

When someone pastes your link into a chat or social post, the app reads a few tags to draw a preview card.

The protocol

The Open Graph protocol, published at ogp.me, turns a web page into an object by adding meta tags in the head. Its page lists four required properties for every page:

PropertyMeaning
og:titleThe title of the object as it should appear
og:typeThe type of the object, for example website or article
og:imageAn image address that represents the object
og:urlThe canonical address of the object, used as its permanent ID

Optional ones include og:description and og:site_name. The tags look like <meta property="og:title" content="...">. Note that they use property, not name.

Tips

  1. Use a full https address for the image and make sure it can be opened without a login.
  2. Use the same address in og:url and in the canonical link.
  3. Write the title and description for the card: they can differ a little from the page's own.
  4. After a change, apps often keep the old preview for a while. Most apps have a debugging page that makes them read the page again.

Check the tags

Use the generator to make them, and read them back in the page source. The generator warns when an image address is not a full address and when og:url is missing.

What size should the image be?

We could not confirm a size from the protocol page, which does not set one, so we give none. Check the guidance of the app where your link will be shared.

Does Open Graph affect search ranking?

The protocol is for link previews. We found no statement in Google's documentation that it is used for ranking.
