How MCP is built: hosts, clients, servers

Three participants, two layers and three kinds of things a server can offer.

Read on 14 November 2026. This field changes fast: check the sources.

Participants

The architecture page names three:

ParticipantWhat it is
MCP hostThe AI application that coordinates and manages one or more MCP clients
MCP clientA component that keeps a connection to one MCP server and gets context from it for the host
MCP serverA program that provides context to MCP clients

Its example: Visual Studio Code is a host. When it connects to a server, it creates a client object to keep that connection; for another server it creates another client. A server can run on your own computer (local) or elsewhere (remote). The page says local servers that use the stdio transport typically serve a single client, while remote servers that use the Streamable HTTP transport typically serve many.

Two layers

  • Data layer: a JSON-RPC based protocol for client-server communication: capability and version discovery, the core primitives (tools, resources, prompts) and notifications.
  • Transport layer: how the messages travel, including connection set-up, message framing and authorization.

Three primitives

According to the server concepts page:

PrimitiveWhat it offersWho controls it
ToolsFunctions the model can call, each doing one operation with typed inputs and outputs (JSON Schema)The model
ResourcesStructured data that the application can retrieve and give to models as contextThe application
PromptsReusable templates with parametersThe user, by explicit invocation

Each primitive has methods to list (*/list), retrieve (*/get) and sometimes execute (tools/call). A client first lists, for example tools/list, and then calls: listings can change over time.

What is JSON-RPC?

A simple format for sending a request with a method name and receiving a result or an error, in JSON. The checker on the home page tests the shape of such messages.

Do I need to run a server on the internet?

No. A stdio server runs on your own computer and talks through standard input and output.
