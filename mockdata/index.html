Fields (columns)

How to use it

  1. Tick the fields you want as columns.
  2. Choose the number of rows, a seed and a format.
  3. Copy the text or download the file.

Same seed, same data

The rows come from a seed, so the same seed with the same fields gives the same file. Use a fixed seed in tests so that failures can be repeated, and change the seed to get a different set.

What is invented

Names are made up from short lists of common Indian first names and surnames. Cities are real Indian cities with their states. E-mail addresses end in example.com, a name reserved for examples. Dates, ages, scores and amounts are random within the ranges shown. There are no ID, account or phone numbers.

Is the data random enough for security?

No. It is for tests, not for passwords or keys.

Does it leave my browser?

No. Everything is made in your browser.
