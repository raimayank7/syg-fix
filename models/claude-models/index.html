Notes from the pages

  • The overview page names claude-fable-5-2, claude-opus-5-5, claude-sonnet-5-5 and claude-haiku-5-5 as the model ID aliases of the four newest models.
  • For Haiku 5.5 the pricing page shows "From $0.10" input and "From $0.50" output, and says that its prices are higher for prompts over 100,000 tokens: read the page for the exact figures.
  • The Batch API gives a 50 percent discount on both input and output tokens (Anthropic pricing page).
  • The pricing page also lists prompt caching prices, fast mode and data residency multipliers. This site does not include them.

What the columns mean

The context window is how many tokens the model can take in a request, and the maximum output is the most it can write in one answer. The input and output prices are charged per million tokens of each kind.

Are newer models always more expensive?

Not in the table: Claude Opus 4.5 and Claude Opus 5.5 are listed at $5 and $4 for input, for example. The table is a snapshot: read it, do not guess.

Which model is best?

This site does not rank models. Test your own task on the models that fit your budget.
