Voltage divider calculator

Enter the input voltage and the two resistors. Add a load resistance to see how much it pulls the output down.

The formula

For two resistors in series across a voltage, the output taken across R2 is Vout = Vin × R2 / (R1 + R2).

The target feature

Give R1, the input and the output you want, and leave R2 empty. The tool gives R2 = R1 × Vout / (Vin − Vout) and the nearest E24 value.

Loading

A divider works only if whatever you connect to the output draws very little current. If it draws a lot, the load is in parallel with R2 and lowers the output. The page on divider limits has a worked example.

How it was tested

300 random dividers were compared with direct calculation, with and without a load, and the loaded output was always lower than the unloaded one.

Can I use a divider to power something?

Only a tiny load. For power, use a regulator.

What values should I choose?

A current of a fraction of a milliampere through the divider is typical for signals. Lower resistor values waste more power.
