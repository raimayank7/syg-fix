Git command cheat sheet from tested examples

Each command here appears in a situation page where its output is shown.

Before you run anything destructive

  1. Run git status and read it.
  2. Save work you might want: git branch backup costs nothing.
  3. Remember that git reflog can recover many mistakes for a while. The defaults, from the Git documentation, are 90 days for entries that can still be reached and 30 days for those that cannot.
