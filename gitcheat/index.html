Guides

How these pages work

Git problems have a small number of causes. Each page here takes one situation, shows the commands, and shows what Git printed when we ran them. You can compare your screen with ours.

Before you start

  1. Run git status. It tells you which branch you are on and what is changed.
  2. If the work matters, make a copy of the branch first: git branch backup.
  3. Do not rewrite commits that others already have.
Do I need to know Git well?

No. Each page is written for a person who has made one specific mistake.

Will these commands work with GitHub?

Yes for the local steps. Pushing and pulling are not covered here.
