GitHub Pages limits

GitHub Pages is free and simple, with limits that matter once a site grows.

Read on 14 November 2026. Limits change: check the source before you decide.

The limits

According to GitHub's page on Pages limits, read on 14 November 2026:

LimitValue
Source repositoryRecommended limit of 1 GB
Published siteNo larger than 1 GB
Deployment timeTimes out after 10 minutes
BandwidthSoft limit of 100 GB per month
BuildsSoft limit of 10 builds per hour (does not apply if you build and publish with a custom GitHub Actions workflow)
Rate limitsMay apply: a request that hits one gets HTTP 429 with an explanation
User or organization sitesOne per account

"Soft" means GitHub may ask you to change something if you go over, and it says that if your site exceeds the usage quotas, you may receive a message asking you to reduce the usage or consider another hosting service.

Allowed use

The same page says that GitHub Pages is not intended for or allowed to be used as a free web-hosting service to run your online business, an e-commerce site, or any other website that is primarily directed at facilitating commercial transactions or providing commercial software as a service. It also says that Pages sites shouldn't be used for sensitive transactions like sending passwords or credit card numbers. A site that shows content, tools and ads is a different case from a shop or a paid web application, but the rule is GitHub's to interpret: read it yourself.

What this means in practice

  1. A content site of a few hundred megabytes fits easily.
  2. Watch the 100 GB a month figure if you serve large images or downloads. Use the "will my site fit" check on the home page.
  3. Many small sites built from one repository can be made into several repositories, as each published site has its own 1 GB limit.
  4. For anything that takes payments, use a host that allows it.
Can I use my own domain?

Yes. See the DNS section of this site for the records.

Is 100 GB a lot?

At a page weight of 1 MB that is 100,000 page views a month.
