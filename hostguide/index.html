Will my site fit the free plan?

Limits read on 14 November 2026. Check them again before you decide.

How to use it

  1. Enter the size and file count of your built site (the folder you publish), the biggest file, and your traffic.
  2. Read the verdict for each host: it lists each limit with your figure next to it.
  3. Open the guide of a host to see where the limit is documented.

What the check includes

GitHub Pages: the 1 GB site size and the 100 GB soft monthly bandwidth. Cloudflare Pages Free plan: files, file size and builds per month. Netlify Free plan: the credits for bandwidth, requests and production deploys against the 300 credit limit. Compute, forms and other metered items are not included.

The date

The limits are those on the hosts' pages on 14 November 2026. They change, so check the pages named in the guides before you move.

Does it test my site?

No. It does arithmetic from the numbers you type and the limits we read.

Where do I get my numbers?

The folder properties give size and file count. Your analytics gives visits and page weight.

Guides

This is an independent guide. It is not connected with GitHub, Cloudflare, Netlify or any host named here. Limits and prices change: everything on this page was read on 14 November 2026 from the pages named under Sources. Check them again before you decide.
